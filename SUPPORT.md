# Getting help

## Using a tool, benchmark or kit

Start with the repository README. If something is unclear or broken, open an issue in that repository and pick the form that fits: bug report, question, or request. Please leave out personal data, client data and API keys.

## Requests for new open data or tools

Use the "Dataset, tool or benchmark request" form in any Bayanat Labs repository. We review requests when we plan what to build next. A request is not a commitment to build something or to a date.

## Data built for your product

Our open repositories are free and supported on a best-effort basis. If you need Arabic data built, annotated or evaluated for your own product, the fastest route is a [pilot](https://www.bayanatlabs.com/pilot). You can also [talk to us](https://www.bayanatlabs.com/company#contact).

## Removal requests

To ask us to remove personal data or other content from anything we publish, email [hello@bayanatlabs.com](mailto:hello@bayanatlabs.com) with "Removal request" in the subject. Include the repository and the file or record.

## Security

Follow our [security policy](https://github.com/Bayanat-Labs/.github/blob/main/SECURITY.md). Please do not open a public issue.
